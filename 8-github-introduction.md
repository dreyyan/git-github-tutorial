# GitHub - Introduction

## What Is GitHub?
GitHub is a platform for hosting Git repositories, enabling collaboration, code review, and project management. Built around Git, it adds a user-friendly interface and tools for teams.

- **Purpose**: Centralized hosting for Git repositories with features for collaboration and project tracking.
- **Popularity**: Widely used for open-source and private projects, with millions of repositories hosted.

## Key Features of GitHub
GitHub extends Git’s functionality with:

- **Repositories**: Host and manage Git repositories with version history and access controls.
- **Pull Requests**: Facilitate code reviews and discussions before merging changes.
- **Issues**: Track bugs, feature requests, or tasks with a built-in issue tracker.
- **GitHub Actions**: Automate workflows like testing, building, or deploying code.
- **Wikis and Pages**: Create documentation (Wikis) or host static websites (GitHub Pages).

## Setting Up a GitHub Account
Get started with GitHub:

- Visit [github.com](https://github.com) and sign up for a free account.
- Verify your email address to activate your account.
- Optional: Set up two-factor authentication for added security.
- Create your first repository via the web interface or by pushing a local repository with `git push origin main`.
